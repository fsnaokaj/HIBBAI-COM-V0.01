# Hibbai!

Shop, chat, and win. Hibbai is a deals community with a shop, forums, cart, and account.

## Pages

- `/` — full site (shop, cart, checkout, account, forums, brand kit)
- `/hibbai_shop` — shop home
- `/hibbai_forums` — forums
- `/hibbai_cart` — cart
- `/hibbai_account` — account
- `/hibbai_brand_kit` — brand kit
- `/hibbai_category_*` — category shelves

Cart and account state persist in the browser.

## Local

Open `index.html` in a browser, or:

```bash
npx serve .
```
